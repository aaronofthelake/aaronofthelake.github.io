# Aaron Lake — personal site (draft v3)

One-page personal site intended for GitHub Pages at `aaronofthelake.github.io`.

**Theme:** Alberta badlands photo header with light aviation touches (small ALT/HDG note, flight-path timeline).

**Status:** local draft only. No remote, no Pages enablement, not live.

## Contents

- `index.html` — single page
- `styles.css` — styles (no build step, no CDN, no trackers)
- `assets/hero-badlands-1920.jpg` — header photo, desktop (1920×1080, ~350 KB)
- `assets/hero-badlands-800.jpg` — header photo, mobile crop (800×889, ~130 KB)
- `assets/aaron-headshot.jpg` — LinkedIn public profile photo
- `assets/article20_silent_agent.jpg` — Badlands article graphic
- `preview-v3.png` / `preview-v3-mobile.png` / `preview-v3-hero.png` — review screenshots (1280 and 390 wide)
